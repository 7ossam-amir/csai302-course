# Lab 8 home practice

Implement the recoverable page store described in `STUDENT_TASK.md`. The starter
is in `student.py`; `test_student.py` contains the public contract checks.

From the repository root, use the existing course environment:

```powershell
.\.venv\Scripts\python.exe labs\lab08\practice\test_student.py
```

When you finish, continue with the [worksheet](WORKSHEET.md): explain code, draw
diagrams, predict output, and complete `worksheet.py`, checked with:

```powershell
.\.venv\Scripts\python.exe labs\lab08\practice\test_worksheet.py
```

The tests fail while the starter methods are unfinished. Add your own tests, the
checkpoint experiment, your results report, and your disaster recovery plan as
described in the assignment. Do not edit the public tests.
